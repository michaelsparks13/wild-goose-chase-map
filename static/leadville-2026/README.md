# leadville-2026 — passthrough, not a template map

`index.html` is **generated by a different pipeline** and copied here verbatim.
It has no `config.js` and does not go through `buildMap()`; `build.js` copies
`static/` into `dist/` untouched, so this lands at `/leadville-2026/`.

Source of truth:

    ../../../cinematic-maps/          (repo: cinematic-maps)
      data/leadville-interactive/     race data, sources, verification
      features/crew-console/          the page's runtime feature

Regenerate:

    cd ../../../cinematic-maps
    python3 data/leadville-interactive/build-data.py
    node build.mjs leadville-interactive
    node tests/verify-crew-console.mjs          # both gates must pass
    cp demo/leadville-interactive/index.html \
       ../interactive-maps/static/leadville-2026/index.html

Do not hand-edit `index.html`. Every change belongs upstream, or it is lost on
the next regeneration.
